# Пунктуация при оборотах, не являющихся придаточными предложениями

## § 114. Цельные по смыслу выражения

| Формулировка |
|---|
| Не выделяются запятыми цельные по смыслу выражения, которые не являются придаточными предложениями. |

| Примеры |
|---|
| делать как следует |
| пойти куда глаза глядят |
| кричать что есть мочи |
| делать что хочешь |
| бежать сломя голову |
| работать не покладая рук |

---

## § 115. Сравнительные обороты

| Формулировка |
|---|
| Сравнительные обороты с союзами **как**, **словно**, **будто**, **как будто**, **точно**, **чем** выделяются запятыми. |

| Примеры |
|---|
| Он бежал, как ветер. |
| Глаза блестели, словно звёзды. |
| Дом стоял, будто крепость. |

| Примечание |
|---|
| Запятая не ставится, если оборот с **как** имеет значение «в качестве» или входит в состав сказуемого. |

| Примеры |
|---|
| Он работает как инженер. (в качестве) |
| Он смотрел как заворожённый. (в составе сказуемого) |
