# Знаки препинания при повторяющихся словах

## § 90. Запятая при повторяющихся словах

| Формулировка |
|---|
| Между повторяющимися словами ставится запятая, если повторение используется для усиления, длительности действия или для обозначения большого количества предметов. |

| Примеры |
|---|
| Еду, еду в чистом поле (Пушкин). |
| Всё дальше, дальше мчится поезд. |
| За синими, синими морями. |

---

## § 91. Дефисное написание повторяющихся слов

| Формулировка |
|---|
| Повторяющиеся слова пишутся через дефис, если они образуют сложное слово. |

| Примеры |
|---|
| еле-еле, чуть-чуть, крепко-накрепко |
| похожи-похожи, день-деньской |
