# Стилистика — правила и рекомендации

Планируемые файлы:

- `01-functional-styles.md` — Функциональные стили (научный, офиц.-деловой, публиц., художественный, разговорный)
- `02-lexical.md` — Лексическая стилистика (точность, чистота, богатство, уместность)
- `03-morphological.md` — Морфологическая стилистика (вариантные падежные формы, род, число)
- `04-syntactic.md` — Синтаксическая стилистика (порядок слов, параллелизм, парцелляция)
- `05-tropes.md` — Тропы (метафора, метонимия, эпитет, сравнение, олицетворение)
- `06-figures.md` — Фигуры речи (анафора, антитеза, градация, инверсия)
