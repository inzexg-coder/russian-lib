# Проверяемые безударные гласные корня

Безударные гласные корня проверяются ударением, т. е. в неударяемом слоге пишется та же гласная, что и в соответствующем ударяемом слоге однокоренного слова.

## Основное правило

| Пример | Проверочное слово |
|---|---|
| трава | травы |
| стена | стены |
| плечо | плечи |
| река | реки |
| весна | вёсны |
| звезда | звёзды |
| число | числа |
| земля | земли |
| нора | норы |
| роса | росы |
| волна | волны |
| сосна | сосны |
| доска | доски |
| гора | горы |
| носить | носит |
| ходить | ходит |
| варить | варит |
| дарить | дарит |
| лесной | лес |
| морской | море |
| полевой | поле |
| степной | степь |
| водный | воды |
| земной | земли |
| вечерний | вечер |
| домашний | дом |

### Примеры различения на письме

| Слово | Проверка | Слово | Проверка |
|---|---|---|---|
| примерять (костюм) | мерить | примирять (соседей) | мир |
| развевается (флаг) | веять | развивается (промышленность) | развитие |

## Паронимы, различающиеся безударной гласной корня

Безударные гласные различают на письме слова, совпадающие в произношении (омофоны). Ниже приведены основные пары русского языка:

| Слово 1 | Проверка | Значение | Слово 2 | Проверка | Значение |
|---|---|---|---|---|---|
| залезать | лезть | карабкаться (в карман) | зализать | лижет | заживлять языком (раны) |
| отварить | варит | сварить (картофель) | отворить | затвор | открыть (дверь) |
| поласкать | ласка | приласкать (кошку) | полоскать | полощет | промывать (рот) |
| пристежной | стёжка / пристегнуть | пристёгивающийся (воротник) | пристяжной | стягивать / упряжь | запрягаемый сбоку (конь) |
| разредить | редкий | сделать редкими (всходы) | разрядить | разряд | опустошить (ружьё) |
| умалять | малый | принижать (значение) | умолять | молит | упрашивать (о пощаде) |
| поседеть | сед | стать седым (от горя) | посидеть | сидя | сидеть некоторое время (на скамейке) |
| обежать | бег | обогнуть (вокруг дома) | обижать | обида | оскорблять (слабого) |
| запевать | петь | начинать петь (песню) | запивать | пить | запивать едой (водой) |
| посветить | свет | светить (фонарём) | посвятить | свято | посвятить (другу, стихи) |
| проживать | жить | жить (в городе) | прожевать | жёваный | разжевать (пищу) |
| слезать | слезть | спускаться (с крыши) | слизать | лижет | убрать языком (сметану) |
| свила | вить | свила (гнездо) | свела | свёл | свела (вместе) |
| старожил | старый | давно живущий (старожил города) | сторожил | сторож | охранял (сторожил склад) |
| навевать | веять | навевать (воспоминания) | навивать | вить | навивать (проволоку) |
| обвевать | веять | обдувать (ветром) | обвивать | вить | обматывать (вокруг) |
| вывевать | веять | выдувать (мусор) | вывивать | вить | развивать (косу) |
| увядать | вянуть | вянуть (на солнце) | увидать | видеть | увидеть (вдали) |
| чистота | чистый | чистота (в доме) | частота | частый | частота (звука) |
| леса | лес | лесные массивы | лиса | лисы | животное |
| наколоть | колет | наколоть (дров) | накалить | накал | сильно нагреть |

## Примечание 1

Гласные **о – а** в неударяемых корнях глаголов совершенного вида **нельзя** проверять формами несовершенного вида на **-ывать (-ивать)**, например:

| Глагол сов. вида | Проверка (ударение) | Несов. вид на -ывать/-ивать (не является проверкой) |
|---|---|---|
| опоздать | поздний | опаздывать |
| раскроить | кройка | раскраивать |

---

## Примечание 2

В некоторых словах иноязычного происхождения с выделяемым только этимологически суффиксом написание безударной гласной **нельзя** проверять однокоренным словом, если проверяемая и проверочная гласные входят в состав **суффиксов различного происхождения**, например:

| Слово | Суффикс / происхождение | Однокоренное слово | Суффикс / происхождение |
|---|---|---|---|
| абонемент | -емент (фр.) | абонировать | -ировать (нем.) |
| аккомпанемент | -емент (фр.) | аккомпанировать | -ировать (нем.) |
| ангажемент | -емент (фр.) | ангажировать | -ировать (нем.) |

А также при различном происхождении корня:

| Слово | Однокоренное слово | Пояснение |
|---|---|---|
| апперципировать | апперцепция | лат. -cip- / -cept- |
| дезинфицировать | дезинфекция | лат. -fic- / -fect- |

### Сохранение гласной корня

В следующих словах гласная корня сохраняется в родственных словах, несмотря на различие в морфемном составе:

| Слово | Родственное слово | Корень |
|---|---|---|
| инъекция | инъецировать | -инъек- / -инъец- |
| проекция | проецировать | -проек- / -проец- |
