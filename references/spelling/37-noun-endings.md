# Окончания имен существительных

## Гласная и перед падежными окончаниями

| Формулировка |
|---|
| В существительных, имеющих перед падежными окончаниями гласную **и**, пишется в предложном падеже единственного числа (у слов женского рода также в дательном падеже) буква **и**. |

### Примеры

| Пример | Примечание |
|---|---|
| о гении | |
| в гоголевском «Вии» | |
| на бильярдном кии | |
| сестрам Марии, Евгении, Ии и Лии | |
| по реке Бии | |
| на лезвии | но: *на остриé* (под ударением) |

---

## Существительные среднего рода на -ье

| Формулировка |
|---|
| В существительных среднего рода на **-ье** в предложном падеже единственного числа пишется буква **е**. |

### Примеры

| Пример | Примечание |
|---|---|
| мечта о счастье | |
| на Рижском взморье | |
| жить в Закавказье | но: *в забытьú* (под ударением) |

---

## Родительный падеж множественного числа

| Формулировка |
|---|
| Существительные на неударяемые **-ья** и **-ье** имеют в родительном падеже множественного числа окончание **-ий**, а на ударяемые **-ья** и **-ьё** – окончание **-ей**. |

### Примеры

| Неударяемые (-ий) | Ударяемые (-ей) |
|---|---|
| шалунья – шалуний | скамья – скамей |
| запястье – запястий | ружьё – ружей |
| | но: копьё – копий |

---

## Существительные на -ня

| Формулировка |
|---|
| В родительном падеже множественного числа существительных на **-ня** с предшествующим согласным или **й** буква **ь** на конце не пишется. |

### Примеры

| Пример |
|---|
| вишня – вишен |
| градирня – градирен |
| бойня – боен |

| Исключения |
|---|
| барышень, боярышень, деревень, кухонь |

---

## Творительный падеж фамилий

| Формулировка |
|---|
| Русские фамилии на **-ов(-ёв)**, **-ев**, **-ин**, **-ын** имеют в творительном падеже единственного числа окончание **-ым**, иностранные фамилии на **-ов** и **-ин** – окончание **-ом**. |

### Примеры

| Русские (-ым) | Иностранные (-ом) |
|---|---|
| Некрасовым | Бюловом |
| Соловьёвым | Вирховом |
| Плещеевым | Дарвином |
| Никитиным | Чаплином |
| Птицыным | |

---

| Формулировка |
|---|
| Названия населенных пунктов на **-ов**, **-ев**, **-ин**, **-ын**, **-ово**, **-ево**, **-ино**, **-ыно** имеют в творительном падеже окончание **-ом**. |

### Примеры

| Пример |
|---|
| за Львовом |
| под Киевом |
| за Калинином |
| над Быковом |
| за Уклеевом |
| под Бородином |
| за Голицыном |

---

## Существительные с суффиксом -ищ-

| Формулировка |
|---|
| Существительные мужского и среднего рода с суффиксом **-ищ-** имеют в именительном падеже единственного числа окончание **-е**, существительные женского рода – окончание **-а**. |

### Примеры

| Мужской/средний род (-е) | Женский род (-а) |
|---|---|
| дом – домище | рука – ручища |
| болото – болотище | грязь – грязища |

---

| Формулировка |
|---|
| Слова мужского рода типа *домище* в именительном падеже множественного числа наряду с окончанием **-а** имеют в разговорной речи окончание **-и**, в результате чего образуются дублетные формы. |

### Различие по значению

| Слово | Им. п. мн. ч. | Значение |
|---|---|---|
| топорище | топорищи | большой топор |
| топорище | топорища | рукоятка топора |
| городище | городищи | большой город |
| городище | городища | древнее поселение |

---

## Существительные с суффиксами -ушк-, -юшк-, -ышк-, -ишк-

| Формулировка |
|---|
| У существительных с суффиксами **-ушк-**, **-юшк-**, **-ышк-**, **-ишк-** в именительном падеже единственного числа пишется окончание **-а** у слов мужского рода, обозначающих одушевленные предметы, и у слов женского рода; окончание **-о** у слов мужского рода, обозначающих неодушевленные предметы, и у слов среднего рода. |

### Примеры

| -а (одуш. муж. / жен. род) | -о (неодуш. муж. / сред. род) |
|---|---|
| дедушка | городишко |
| батюшка | хлебушко |
| парнишка | голосишко |
| матушка | грязюшка (ср. р.) |
| долюшка | полюшко |
| | морюшко |
