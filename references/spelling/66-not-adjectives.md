# Правописание не с прилагательными

## § 66. Правописание не с именами прилагательными

### Слитное написание

| Формулировка |
|---|
| **Не** с прилагательными пишется слитно, если слово не употребляется без **не**; если слово приобретает противоположное значение (можно заменить синонимом без **не**); при наличии пояснительных слов, как правило, слитное написание сохраняется. |

| Примеры |
|---|
| незнакомый нам автор |
| неизвестные науке факты |
| неуместное в данных условиях замечание |
| незаметная на первый взгляд ошибка |
| непонятные ученику слова |
| ненужные для дела подробности |
| поведение, недостойное порядочного человека |
| площадка, непригодная для стройки |

| Примечание |
|---|
| Наличие пояснительных слов, как правило, не влияет на слитное написание **не** с прилагательными (ср. написание **не** с причастиями, § 70, п. 2). |

---

### Раздельное написание

| Формулировка |
|---|
| **Не** с прилагательными пишется раздельно при противопоставлении (с союзом **а**) или если отрицание логически подчеркивается. |

| Примеры |
|---|
| не большой, а маленький |
| не добрый, а злой |
| не правдивый, а лживый |

| Примечание |
|---|
| Если противопоставление выражено союзом **но**, то прилагательные с **не** обычно пишутся слитно, так как противопоставляются не прямо противоположные понятия, а совместимые. |
