# Гласные ы и и после приставок

| Формулировка |
|---|
| После приставок, оканчивающихся на согласную, вместо **и** пишется **ы** в соответствии с произношением. |

### Примеры

| Исходное слово | После приставки |
|---|---|
| играть | подыграть, разыграть, сыграть |
| искать | отыскать, подыскать, разыскать |
| идейный | безыдейный |
| индукционный | безындукционный |
| интегральный | подынтегральный |
| исторический | предысторический |
| июльский | предыюльский |

---

| Примечание 1 |
|---|
| Данное правило не распространяется на сложносокращенные слова, например: *пединститут*, *спортинвентарь*. |

| Примечание 2 |
|---|
| В слове *взимать* пишется **и** согласно произношению. |

---

## После приставок меж- и сверх-

| Формулировка |
|---|
| После приставок **меж-** и **сверх-** сохраняется **и**, так как по общему правилу после шипящих и заднеязычных не пишется **ы**. |

### Примеры

| Слово |
|---|
| межинститутские соревнования |
| межимпериалистические противоречия |
| сверхизысканный |
| сверхиндустриализация |
| двухимпульсный и т. п. |

---

## После иноязычных приставок

| Формулировка |
|---|
| Сохраняется **и** после иноязычных приставок и частиц **дез-**, **контр-**, **пост-**, **суб-**, **супер-**, **транс-**, **пан-**. |

### Примеры

| Слово |
|---|
| дезинформация |
| контригра |
| постимпрессионизм |
| субинспектор |
| суперинтендант |
| трансиорданский |
| панисламизм |

| Сравнение |
|---|
| *предынфарктный* – *постинфарктный* (разные приставки) |
