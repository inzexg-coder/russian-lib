# Географические и административно-территориальные названия

| Формулировка |
|---|
| С прописной буквы пишутся собственные географические наименования. |

### Примеры

| Слово | Примечание |
|---|---|
| Арктика | |
| Европа | |
| Финляндия | |
| Москва | |
| Кремль | район города, но: *в древнерусских городах строили кремль* (в значении «крепость») |
| анти-Франция | |

## Составные названия

| Формулировка |
|---|
| В составных названиях с прописной буквы пишутся все слова, кроме служебных слов и родовых наименований (слов *гора*, *город*, *залив*, *море*, *озеро*, *остров*, *река*, *улица* и т. д.). |

### Примеры

| Пример | Пример |
|---|---|
| Северная Америка (обе Америки, открывать Америку) | Старый Свет |
| Новый Свет | Южная Африка |
| Азиатский материк | Северный Ледовитый океан |
| Кавказское побережье | Европейская Россия (но: европейская часть России) |
| Южный полюс | тропик Рака |
| Красное море | остров Новая Земля |
| мыс Доброй Надежды | Берингов пролив |
| Главный Кавказский хребет | река Нижняя Тунгуска |
| город Санкт-Петербург | город Великие Луки |
| город Сергиев Посад | улица Пограничника Гарькавого |
| Малый Афанасьевский переулок | шоссе Энтузиастов |
| Большой Каменный мост | станция Ерофей Павлович |

---

| Формулировка |
|---|
| То же в сочетаниях, относящихся к текстам из военной литературы. |

### Примеры

| Пример |
|---|
| Южный фронт |
| 1-й Белорусский фронт |
| Волоколамское направление |

## Нарицательные существительные в составных названиях

| Формулировка |
|---|
| Нарицательные существительные в составных географических названиях пишутся с прописной буквы, если они употреблены не в прямом значении и называют объект условно. |

### Примеры

| Пример |
|---|
| Белая Церковь (город) |
| Красная Поляна (город) |
| Красная Горка (город) |
| Чешский Лес (горный хребет) |
| Золотой Рог (бухта) |
| Канин Нос (мыс) |

---

| Формулировка |
|---|
| В названиях, отражающих прошлое Москвы, пишутся по традиции. |

### Примеры

| Пример |
|---|
| Чистые пруды (улица в Москве, на которой имеются пруды) |
| Кузнецкий мост (улица в Москве) |
| Никитские ворота |
| Коровий брод |
| Каретный ряд |

---

## Титулы, звания в географических названиях

| Формулировка |
|---|
| Названия титулов, званий, должностей и т. д. в составных географических наименованиях пишутся с прописной буквы. |

### Примеры

| Пример |
|---|
| острова Королевы Шарлотты |
| остров Земля Принца Карла |
| мост Лейтенанта Шмидта |
| остров Святой Елены |
| залив Святого Лаврентия |

## Части сложных географических названий (дефис)

### а) Два существительных

| Пример |
|---|
| Эльзас-Лотарингия |
| Шлезвиг-Гольштейн |
| мыс Сердце-Камень |
| поселок Майдан-Бобрик |

### б) Существительное с прилагательным

| Пример |
|---|
| Новгород-Северский |
| Переславль-Залесский |

### в) Сложное прилагательное

| Пример |
|---|
| Западно-Сибирская низменность |
| Военно-Грузинская дорога |
| Волго-Донской канал |

### г) Элементы верх-, соль-, усть-

| Пример |
|---|
| Верх-Нейвинский |
| Соль-Илецк |
| Усть-Ишим |
| Сольвычегодск (слитно, по традиции) |

### д) Иноязычные элементы

| Пример |
|---|
| Алма-Ата («отец яблок») |
| Норд-Кап («северный мыс») |
| Нью-Йорк («новый Йорк») |

## Иноязычные родовые наименования

| Формулировка |
|---|
| С прописной буквы пишутся иноязычные родовые наименования, входящие в состав географических названий, но не употребляющиеся в русском языке как нарицательные существительные. |

### Примеры

| Пример |
|---|
| Йошкар-Ола (*ола* – город) |
| Рио-Колорадо (*рио* – река) |
| Сьерра-Невада (*сьерра* – горная цепь) |

---

| Формулировка |
|---|
| Иноязычные родовые наименования, вошедшие в присущем им значении в русский язык в качестве нарицательных существительных, пишутся со строчной буквы. |

### Примеры

| Пример |
|---|
| Варангер-фиорд (слово *фиорд* — географический термин) |
| Беркли-сквер (также: Уолл-стрит, Бейкер-стрит, где *стрит* – улица) |

---

## Артикли, предлоги, частицы в иноязычных названиях

| Формулировка |
|---|
| Артикли, предлоги, частицы, находящиеся в начале иноязычных географических названий, пишутся с прописной буквы и присоединяются дефисом. |

### Примеры

| Пример |
|---|
| Ла-Валлетта |
| Лас-Вегас |
| Ле-Крезо |
| Лос-Эрманос |
| Де-Лонга |
| Сан-Франциско |
| Санта-Крус |
| Сен-Готард |
| Сент-Этьенн |

---

| Формулировка |
|---|
| Служебные слова, находящиеся в середине русских и иноязычных сложных географических названий, пишутся со строчной буквы и соединяются двумя дефисами. |

### Примеры

| Пример |
|---|
| Ростов-на-Дону |
| Франкфурт-на-Майне |
| Рио-де-Жанейро |
| Пинар-дель-Рио-Дос |
| Шуази-ле-Руа |
| Орадур-сюр-Глан |
| Сан-Франциско-де-ла-Калета |
| Абруццо-э-Молизе |
| Дар-эс-Салам |

---

## Названия стран света

| Формулировка |
|---|
| Названия стран света, когда они входят в состав территориальных названий или употребляются взамен территориальных названий, пишутся с прописной буквы. |

### Примеры

| Пример |
|---|
| народы Востока (т. е. восточных стран) |
| Дальний Восток |
| Крайний Север |

| Примечание |
|---|
| В прямом значении названия стран света пишутся со строчной буквы: *восток*, *запад*, *север*, *юг*. |

## Официальные названия государств

| Формулировка |
|---|
| В официальных названиях государств все слова, как правило, пишутся с прописной буквы. |

### Примеры

| Пример |
|---|
| Российская Федерация |
| Республика Беларусь |
| Республика Украина |
| Республика Молдова |
| Республика Армения |
| Республика Нигер |
| Соединенные Штаты Америки |
| Швейцарская Конфедерация |
| Соединенное Королевство Великобритании и Северной Ирландии |
| Французская Республика |
| Южно-Африканская Республика |
| Объединенные Арабские Эмираты |

| Формулировка |
|---|
| С прописной буквы пишутся все слова в новых названиях прежних автономий и в новых образованиях. |

### Примеры

| Пример |
|---|
| Республика Саха (Якутия) |
| Республика Марий Эл |
| Республика Коми |
| Республика Башкортостан |

---

| Формулировка |
|---|
| В силу установившейся традиции отдельные слова в официальных названиях государств пишутся со строчной буквы. |

### Пример

| Пример |
|---|
| Великое герцогство Люксембург |

---

## Названия групп государств

| Формулировка |
|---|
| В названиях групп (объединений, союзов) государств с прописной буквы пишутся все слова, кроме родовых наименований. |

### Примеры

| Пример |
|---|
| страны Балтии |
| Скандинавские страны |
| Европейское экономическое сообщество |
| Лига арабских стран |
| Союз государств Центральной Африки |
| Священный союз |
| Тройственный союз (но: Содружество Независимых Государств) |

---

| Формулировка |
|---|
| Родовые наименования в составных неофициальных названиях зарубежных государств пишутся со строчной буквы. |

### Пример

| Пример |
|---|
| Соединенное королевство (Великобритания) |

---

## Части государств

| Формулировка |
|---|
| Названия частей государств, носящие терминологический характер, пишутся с прописной буквы. |

### Примеры

| Пример |
|---|
| Западная Белоруссия |
| Правобережная Украина |
| Внутренняя Монголия |
| Северная Италия |

---

## Образные названия государств

| Формулировка |
|---|
| В образных названиях государств с прописной буквы пишется или первое слово, или слово, подчеркивающее характерный признак называемого объекта. |

### Примеры

| Пример |
|---|
| Страна восходящего солнца (Япония) |
| Страна тюльпанов (Нидерланды) |
| остров Свободы (Куба) |

---

## Административно-территориальные названия

| Формулировка |
|---|
| В административно-территориальных названиях слова, обозначающие родовое или видовое понятие: *область*, *край*, *район* и т. д., – пишутся со строчной буквы, остальные слова – с прописной. |

### Примеры

| Пример |
|---|
| Краснодарский край |
| Курская область |
| Шелковский район |

| Формулировка |
|---|
| В названиях административно-территориальных единиц зарубежных государств с прописной буквы пишутся все слова, кроме родовых обозначений. |

### Примеры

| Пример |
|---|
| графство Суссекс (Англия) |
| департамент Верхние Пиренеи (Франция) |
| штат Южная Каролина (США) |
| округ Колумбия (США) |
| область Тоскана (Италия) |
| земля Баден-Вюртемберг (ФРГ) |
| Шецинское воеводство (Польша) |
| префектура Хоккайдо (Япония) |
| провинция Сычуань (Китай) |
