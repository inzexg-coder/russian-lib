# Разделительные ъ и ь

## § 29. Употребление ъ

| Формулировка |
|---|
| Разделительный **ъ** пишется перед гласными буквами **е, ё, ю, я**. |

### После приставки на согласную

| Формулировка |
|---|
| После приставки, оканчивающейся на согласную, перед гласными **е, ё, ю, я** пишется **ъ**. Перед другими гласными **ъ** не пишется. |

### Примеры

| С ъ | Без ъ |
|---|---|
| подъезд | подоблачный |
| разъём | разукрашенный |
| предъюбилейный | межотраслевой |
| межъядерный | безаварийный |
| | собезьянничать |
| | сэкономить |

### В иноязычных словах

| Формулировка |
|---|
| В иноязычных словах, в которых имеется приставка, оканчивающаяся на согласную (**аб-**, **ад-**, **ин-**, **интер-**, **кон-**, **контр-**, **об-**, **суб-**, **транс-**), или частица **пан-**, пишется **ъ**. |

| Примеры | Исключения |
|---|---|
| адъютант | трансатлантический |
| дизъюнкция | суборбитальный |
| инъекция | |
| конъюнктура | |
| объект | |
| субъект | |
| трансъевропейский | |
| панъяпонский | |

### В сложных словах с числительными

| Формулировка |
|---|
| В сложных словах, первую часть которых образуют числительные **двух-**, **трёх-**, **четырёх-**, пишется **ъ**. |

| Примеры | Исключения |
|---|---|
| двухъярусный | двухатомный |
| трёхъязычный | четырёхэтажный |

---

| Примечание |
|---|
| Данное правило не распространяется на сложносокращенные слова, например: *спецёмкость*, *Госюриздат*, *детясли*. |

---

## § 30. Употребление ь

| Формулировка |
|---|
| Разделительный **ь** пишется перед **е, ё, и, ю, я** внутри слова, не после приставки. |

### Примеры

| Слово |
|---|
| портьера |
| серьёзный |
| соловьиный |
| вьюга |
| крестьянин |
| подьячий (ср. *дьяк*) |

---

| Формулировка |
|---|
| В некоторых иноязычных словах **ь** пишется перед **о**. |

### Примеры

| Слово |
|---|
| карманьола |
| медальон |
| почтальон |
| шампиньон |
