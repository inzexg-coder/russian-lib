# Собственные имена лиц

| Формулировка |
|---|
| С прописной буквы пишутся имена, отчества, фамилии, прозвища, псевдонимы. |

### Примеры

| Пример |
|---|
| Николай Васильевич Гоголь |
| Всеволод Большое Гнездо |
| Пётр Первый |
| Екатерина Великая |
| Александр Невский |
| Лже-Нерон |
| рыцарь Печального Образа (о Дон-Кихоте) |

---

| Примечание |
|---|
| Прозвища пишутся без кавычек, например: *Владимир Красное Солнышко*, *Ричард Львиное Сердце*. Ср.: *служанка по прозвищу Великий Могол*. |

---

| Формулировка |
|---|
| В сложных фамилиях, пишущихся через дефис, каждая часть начинается с прописной буквы. |

### Примеры

| Слово | Слово | Слово |
|---|---|---|
| Салтыков-Щедрин | Миклухо-Маклай | Мамин-Сибиряк |
| Новиков-Прибой | Римский-Корсаков | |

---

| Формулировка |
|---|
| Двойные (тройные и т. д.) нерусские имена пишутся все с прописной буквы, раздельно или через дефис в зависимости от того, склоняются или не склоняются все части. |

### Французские составные имена (дефис)

| Пример |
|---|
| Жан-Жак Руссо (ср.: произведения Жан-Жака Руссо) |
| Пьер-Анри Симон |
| Шарль-Мари-Рене Леконт де Лиль |
| Антуан Франсуа Прево д'Экзиль (при склоняемости первого имени — раздельно) |

### Немецкие составные имена (раздельно)

| Пример |
|---|
| Иоганн Вольфганг Гёте |
| Эрнст Теодор Амадей Гофман |
| Эрих Мария Ремарк |
| Иоганнес Роберт Бехер |
| Ганс Магнус Энцесбергер |
| Иоганн Грегор Мендель |

| Примечание |
|---|
| Дефисное написание *И.-С. Бах* связано с желанием отграничить инициалы двух немецких имен (Иоганн Себастьян) от инициалов русского имени и отчества. |

### Через дефис

| Формулировка |
|---|
| Через дефис пишутся составные части, служащие сами по себе (без фамилии) средством называния. |

| Пример |
|---|
| Франц-Иосиф |
| Мария-Терезия |
| Мария-Антуанетта |
| Мария-Христина-Каролина-Аделаида-Франсуаза-Леопольдина |

## Артикли, предлоги, частицы при нерусских фамилиях

| Формулировка |
|---|
| Артикли, предлоги, частицы при нерусских фамилиях и именах пишутся со строчной буквы и дефисами не присоединяются. |

### Примеры

| Пример | Пример | Пример |
|---|---|---|
| Макс фон дер Грюн | Людвиг ван Бетховен | Густав аф Гейерстам |
| Антуан де Сент-Экзюпери | Роже Мартен дю Гар | Моник де ла Бришольри |
| Гарсиласо дела Вега | Энрике дос Сантос | Эдуардо де Филиппо |
| Кола ди Риенцо | Леонардо да Винчи | Андреа дель Сарто |
| Лукка дела Роббиа | | |

### Восточные имена

| Формулировка |
|---|
| В восточных (арабских, тюркских и др.) личных наименованиях начальная или конечная составная часть, обозначающая социальное положение, родственные отношения и т. д., пишется со строчной буквы и, как правило, присоединяется к последующей части дефисом. |

| Пример |
|---|
| Ахмад эд-Дин |
| Омар аш-Шариф |
| Салах зуль-Фикар |
| Мохаммед эль-Куни |
| Сулейман-паша |
| Измаил-бей |
| Кёр-оглы |
| Турсун-заде |

| Формулировка |
|---|
| С прописной буквы пишется начальное **Ибн**. |

| Пример |
|---|
| Ибн-Рошд (Аверроэс) |
| Ибн-Сина (Авиценна) |
| Ибн-Сауд |

---

| Формулировка |
|---|
| Написание служебного слова с прописной буквы при некоторых фамилиях отражает написание в языке-источнике. |

### Примеры

| Пример | Пример | Пример |
|---|---|---|
| Эдмондо Де Амичис (итал.) | Агриппа Д'Обинье (франц.) | Шарль Де Костер (бельг.) |

| Примечание |
|---|
| Без служебного слова не употребляются: *Де Лонг*, *Ди Витторио*, *Дос Пассос*. |

---

| Формулировка |
|---|
| Служебные слова, слившиеся с фамилией в одно слово или присоединяемые к фамилии при помощи дефиса, пишутся с прописной буквы. |

### Примеры

| Слово |
|---|
| Фонвизин |
| Вандервельде |
| Лагранж |
| Ван-Гог |

---

| Формулировка |
|---|
| С прописной буквы пишутся стоящие перед фамилией **О** (после него ставится апостроф), присоединяемые дефисом **Мак-**, **Сан-**, **Сен-**, **Сент-**. |

### Примеры

| Пример |
|---|
| О'Генри |
| Мак-Доуэлл |
| Сан-Мартин |
| Сен-Жюст |
| Сент-Бёв |

---

| Формулировка |
|---|
| В именах **Дон-Кихот**, **Дон-Жуан** обе части пишутся с прописной буквы и соединяются дефисом, образуя единое собственное имя. |

| Примечание |
|---|
| Если слово **дон** употребляется в значении «господин», оно пишется раздельно со строчной буквы, например: *дон Базилио*, *дон Андреа*. В нарицательном значении слова *донкихот*, *донжуан* пишутся со строчной буквы слитно. |

## Китайские, корейские, вьетнамские и другие имена

| Формулировка |
|---|
| В китайских собственных именах лиц, состоящих из двух частей, обе части пишутся раздельно и с прописной буквы. |

### Примеры

| Пример |
|---|
| Сунь Ятсен |
| Е Шэнтао |
| Ли Пэн |

| Формулировка |
|---|
| В корейских, вьетнамских, бирманских, индонезийских, цейлонских, японских фамилиях и именах все составные части пишутся раздельно с прописной буквы. |

### Примеры

| Пример |
|---|
| Пак Су Ен |
| Ле Тхань Нгу |
| У Дау Ма |
| Манг Ренг Сай |
| Тосиро Мифуне |

| Примечание |
|---|
| Частица **сан** в японских именах пишется со строчной буквы и присоединяется дефисом: *Тояма-сан*. |

## Превращение собственных имен в нарицательные

| Формулировка |
|---|
| Собственные имена лиц, превратившиеся в нарицательные, пишутся со строчной буквы. |

### Примеры

| Слово | Слово | Слово |
|---|---|---|
| меценат | ловелас | альфонс |

| Формулировка |
|---|
| Сохраняется написание с прописной буквы, если фамилия, употребляясь в нарицательном значении, не переходит в разряд существительных нарицательных. |

### Пример

| Пример |
|---|
| Мы… твёрдо были уверены, что имеем своих Байронов, Шекспиров, Шиллеров, Вальтер Скоттов (Белинский). |

### В образном значении

| Пример |
|---|
| Встанешь к полке спиной и руки Наполеоном сложишь. |

---

| Формулировка |
|---|
| Если индивидуальные названия людей употребляются в презрительном смысле как родовые обозначения, то они пишутся со строчной буквы. |

### Примеры

| Слово | Слово |
|---|---|
| презренные носке и шейдеманы (предатели социал-демократы) | квислинги (коллаборационисты) |

---

| Примечание |
|---|
| Названия предметов, видов растений, единиц измерения и т. д., образованные от имен лиц, пишутся со строчной буквы, например: *форд*, *наган*, *френч*, *галифе*, *иван-да-марья*, *бефстроганов*, *ампер*, *вольт*, *рентген*. |

## Религиозные и мифологические имена

| Формулировка |
|---|
| С прописной буквы пишутся индивидуальные названия, относящиеся к области религии и мифологии. |

### Примеры

| Пример | Пример | Пример |
|---|---|---|
| Иисус Христос | Будда | Шива |
| Зевс | Меркурий | Анубис |
| Церера | | |

| Примечание |
|---|
| Если индивидуальные названия мифологических существ употребляются в нарицательном значении или в переносном смысле, то они пишутся со строчной буквы; ср.: *древнеславянский бог грома и молнии Перун* – *метать перуны* (гневаться, сердиться). |

---

| Формулировка |
|---|
| Родовые названия мифологических существ пишутся со строчной буквы. |

### Примеры

| Слово | Слово | Слово |
|---|---|---|
| нимфа | сирена | валькирия |
| бес | | |
