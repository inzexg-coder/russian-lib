# Правописание предлогов

## § 59. Сложные предлоги

| Формулировка |
|---|
| Сложные предлоги **из-за**, **из-под**, **по-за**, **по-над**, **по-под**, **с-под**, **для-ради**, **за-ради** пишутся через дефис. |

### Примеры

| Пример |
|---|
| из-за стола |
| из-под шкафа |
| спрятался по-за корчму (Куприн) |
| по-над берегом моря рысью поскакал (Гайдар) |
| трое едут по-под лесом (Толстой) |

## § 60. Слитное и раздельное написание предлогов и предложных сочетаний

### Слитно

| Формулировка |
|---|
| Пишутся слитно предлоги: **ввиду**, **вместо**, **вроде**, **вследствие**, **наподобие**, **насчёт**, **сверх**. |

| Слитно | Различать |
|---|---|
| ввиду возможных осложнений | в виду города, иметь в виду |
| вроде глубокой траншеи | в роде Артамоновых |
| вследствие засухи | включить в следствие |
| наподобие рычага | |
| справиться насчёт расписания | перевести на счёт предприятия |
| сверх | |

---

### Раздельно

| Формулировка |
|---|
| Пишутся раздельно предлоги: **в виде**, **в связи с**, **в продолжение**, **в течение**, **в заключение**. |

| Раздельно | Различать (сущ. с предлогом) |
|---|---|
| в виде исключения | |
| в связи с отъездом | |
| в продолжение зимнего сезона | сюжетные изменения в продолжении романа |
| в течение двух часов | неожиданные перемены в течении болезни |
| в заключение своего выступления | основные положения в заключении юриста |

| Примечание |
|---|
| Сочетания *в продолжение*, *в течение*, *в заключение* при обозначении времени имеют на конце **е**. |
