# Правописание не с существительными

## § 65. Правописание не с именами существительными

| Формулировка |
|---|
| **Не** с существительными пишется слитно, если слово не употребляется без **не**; если слово приобретает противоположное значение (обычно можно заменить синонимом без **не**); если существительное обозначает лицо и выражает качественный оттенок. |

### Слитно

| Случай | Примеры |
|---|---|
| без не не употребляется | невежда, небылица, невзгода |
| приобретает противоположное значение | неправда (ложь), несчастье (беда) |
| | недруг (враг), неволя (плен) |
| обозначение лиц с качественным оттенком | неряха, невежа |

### Раздельно

| Формулировка |
|---|
| **Не** с существительными пишется раздельно, если есть или подразумевается противопоставление, а также если отрицание логически подчеркивается. |

| Примеры |
|---|
| не правда, а ложь |
| не счастье, а горе |
| не друг, а враг |
