# Проверяемые безударные гласные

| Формулировка |
|---|
| Безударные гласные корня проверяются ударением: в неударяемом слоге пишется та же гласная, что и в соответствующем ударяемом слоге однокоренного слова. |

### Примеры

| Слово | Проверка | Значение |
|---|---|---|
| примерять | ме́рить | мерить одежду |
| примирять | мир | прекращать ссору |
| развевается | ве́ять | колыхаться (о флаге) |
| развивается | развитие | совершенствоваться |

### Близкие по звучанию слова

| Слово | Проверка | Слово | Проверка |
|---|---|---|---|
| залезать (в карман) | ле́зть | зализать (раны) | ли́жет |
| отварить (картофель) | ва́рит | отворить (дверь) | затво́р |
| поласкать (кошку) | ла́ска | полоскать (рот) | поло́щет |
| пристежной (воротник) | стёжка | пристяжной (о лошади) | упря́жь |
| разредить (всходы) | ре́дкий | разрядить (ружье) | разря́д |
| умалять (значение) | ма́лый | умолять (о пощаде) | мо́лит |
| спеши́ (торопись) | спе́шка | спиши́ (перепиши) | пи́шет |

| обежа́ть (вокруг) | бе́г | обижа́ть (кого-то) | оби́да |
| навева́ть (мысли) | ве́ять | навива́ть (наматывать) | вить |
| посвети́ть (осветить) | свет | посвяти́ть (кому-то) | свя́то |
| запева́ть (петь) | пе́ть | запива́ть (водой) | пить |
| частота́ (повторяемость) | ча́сто | чистота́ (опрятность) | чи́сто |

---

| Примечание 1 |
|---|
| Гласные **о — а** в неударяемых корнях глаголов совершенного вида нельзя проверять формами несовершенного вида на **-ывать (-ивать)**. |

| Ошибочная проверка | Правильная проверка |
|---|---|
| опоздать ← опа́здывать (неверно) | опоздать ← по́здний |
| раскроить ← раскра́ивать (неверно) | раскроить ← кро́йка |
| спросить ← спра́шивать (неверно) | спросить ← про́сит |
| закончить ← зака́нчивать (неверно) | закончить ← ко́нчить |
| накопить ← нака́пливать (неверно) | накопить ← ко́пит |
| заморозить ← замора́живать (неверно) | заморозить ← моро́з |
| устроить ← устра́ивать (неверно) | устроить ← стро́й |
| расколоть ← раска́лывать (неверно) | расколоть ← раско́л |

---

| Примечание 2 |
|---|
| В заимствованных словах с суффиксами разного происхождения проверка однокоренным словом невозможна. |

| Нельзя проверять | Происхождение |
|---|---|
| абонемент (-емент фр.) ≠ абонировать (-ировать нем.) | суффиксы разного происхождения |
| аккомпанемент ≠ аккомпанировать | суффиксы разного происхождения |
| ангажемент ≠ ангажировать | суффиксы разного происхождения |
| апперципировать ≠ апперцепция | корни разного происхождения |
| дезинфицировать ≠ дезинфекция | корни разного происхождения |

| Можно проверить |
|---|
| инъекция — инъецировать |
| проекция — проецировать |
