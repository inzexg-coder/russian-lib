# 1. Проверяемые безударные гласные

Безударные гласные корня проверяются **ударением**: в неударяемом слоге пишется та же гласная, что и в соответствующем ударяемом слоге однокоренного слова.

## Правило

Чтобы проверить написание безударной гласной в корне, нужно изменить слово или подобрать однокоренное так, чтобы проверяемая гласная оказалась под ударением.

## Примеры

| Слово | Проверочное слово |
|-------|-------------------|
| примерять (костюм) | мерить |
| примирять (соседей) | мир |
| развевается (флаг) | веять |
| развивается (промышленность) | развитие |
| удивление | диво |
| объединение | единый |
| раскалить (печь) | накал |
| вычищать | чисто |
| увядать (цветок) | вянуть |
| увидать (друга) | видеть |

## Различение омофонов

Слова, одинаково звучащие, но пишущиеся по-разному в зависимости от проверочного слова:

| Слово | Проверочное слово | Слово | Проверочное слово |
|-------|-------------------|-------|-------------------|
| залезать (в карман) | лезть | зализать (раны) | лижет |
| запевать (песню) | петь | запивать (водой) | пить |
| обежать (вокруг) | бег | обижать (слабого) | обида |
| обвевать (ветром) | веять | обвивать (лентой) | вить |
| отварить (картофель) | варит | отворить (дверь) | створка |
| посидеть (на скамье) | сидя | поседеть (от горя) | сед |
| поласкать (кошку) | ласка | полоскать (рот) | полощет |
| пристежной (воротник) | пристёжка | пристяжной (конь) | стягивать |
| прожевать (пищу) | жёваный | проживать (в доме) | жить |
| развеваться (на ветру) | веять | развиваться (быстро) | развитие |
| разредить (всходы) | редкий | разрядить (ружьё) | разряд |

## Примечание 1. Глаголы на -ывать/-ивать

Гласные **о – а** в неударяемых корнях глаголов **совершенного вида** нельзя проверять формами **несовершенного вида** на **-ывать (-ивать)**.

| Глагол (сов. в.) | Проверочное слово | Нельзя проверять через |
|------------------|-------------------|----------------------|
| опоздать | поздний | опаздывать |
| раскроить | кройка | раскраивать |
| затопить | топит | затапливать |
| заколоть | колет | закалывать |
| закопать | копка | закапывать |
| обработать | обработанный | обрабатывать |
| захлопнуть | захлопнутый | захлопывать |

## Примечание 2. Иноязычные слова

В некоторых словах иноязычного происхождения с выделяемым только этимологически суффиксом написание безударной гласной **нельзя проверять** однокоренным словом, если проверяемая и проверочная гласные входят в состав суффиксов **различного происхождения**.

### Примеры

| Слово | Суффикс | Проверочное слово | Суффикс проверочного |
|-------|---------|-------------------|----------------------|
| абонемент | -емент (фр.) | абонировать | -ировать (нем.) |
| аккомпанемент | -емент (фр.) | аккомпанировать | -ировать (нем.) |
| ангажемент | -емент (фр.) | ангажировать | -ировать (нем.) |
| дирижабль | -абль (фр.) | дирижёр | -ёр (фр.) |
| режиссёр | -ёр (фр.) | режим | -им (фр.) |

### Разнокорневые соответствия

| Слово | Проверочное слово | Пояснение |
|-------|-------------------|-----------|
| апперципировать | апперцепция | разные латинские основы |
| дезинфицировать | дезинфекция | основы -фицировать/-фекция |

### Сохраняется гласная корня

| Слово | Проверочное слово |
|-------|-------------------|
| инъекция | инъецировать |
| проекция | проецировать |

### Дополнительные примеры иноязычных слов, где проверка ударением ненадёжна

| Слово | Примечание |
|-------|------------|
| интеллигент | нельзя проверить интеллигенция (разные суффиксы) |
| претендент | нельзя проверить претендовать (разные суффиксы) |
| корреспондент | нельзя проверить корреспонденция (разные суффиксы) |
| диктант | нельзя проверить диктовать (разное происхождение основ) |
| орнамент | нельзя проверить орнаментальный (суффиксы разного происхождения) |
| континент | нельзя проверить континентальный (суффиксы разного происхождения) |
| комплимент | нельзя проверить комплиментарный (разные суффиксы) |
| эксперимент | нельзя проверить экспериментальный (разные суффиксы) |
