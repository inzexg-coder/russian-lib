# Rule: Проверяемые безударные гласные в корне слова

## Formula

Unstressed vowels in a root are written the same as the vowel under stress in a related (однокоренное) word.

**Algorithm:**
1. Identify the root of the word
2. Find a related word where this root vowel is under stress
3. Write the same vowel in the unstressed position

# Rule: Проверяемые безударные гласные в корне слова

## Formula

> Безударная гласная в корне проверяется ударением: в безударном слоге пишется та же гласная, что и в ударном слоге однокоренного слова.

## Algorithm

1. Identify the root morpheme of the word.
2. Find a morphologically related word (однокоренное) where the target vowel is under stress.
3. Write the vowel identical to the stressed form.
4. If no stressed cognate exists, the vowel is непроверяемая (see dictionary).

# Rule: Проверяемые безударные гласные в корне слова

## Formula

Unstressed vowel in a root is written the same as the vowel under stress in a morphologically related word (однокоренное слово).

Algorithm:
1. Identify the root morpheme.
2. Find a cognate word where the target vowel is under stress.
3. Write the same vowel in the unstressed position.
4. If no stressed cognate exists (e.g. соб`ака, коп`ейка), consult dictionary — vowel is непроверяемая.

# Rule: Проверяемые безударные гласные в корне слова

## Formula

> Unstressed vowel in a root is written the same as the vowel under stress in a morphologically related word (однокоренное слово).  
> If the vowel is in an unstressed position, find a cognate where that very vowel is at the stressed syllable and write accordingly.

### Algorithm

1. Locate the root morpheme of the word.
2. Find a cognate (any part of speech) where the target root vowel is under stress.
3. Write the same vowel in the unstressed position.
4. If no stressed cognate exists (e.g. соб`ака, коп`ейка, винегр`ет), the vowel is **непроверяемая** — consult a dictionary.

## 7. Exception: глаголы СВ нельзя проверять через -ывать (-ивать)

For perfective verbs (СВ), the root vowel **cannot** be verified using the imperfective form with the suffix **-ывать / -ивать**, because these suffixes often trigger the alternation **о → а** in the root.

| Perfective (СВ) | Stress test (correct) | Imperfective (НСВ) on -ывать/-ивать (do NOT use as stress test) |
|---|---|---|
| опозд**а**ть | п`оздний | оп`аздывать (root vowel shifts: о→а) |
| раскро**и**ть | кр`ойка | раскр`аивать (root vowel shifts: о→а) |
| спрос**и**ть | спр`осит | спр`ашивать (root vowel shifts: о→а) |
| зак`онч**и**ть | к`ончит | зак`анчивать (root vowel shifts: о→а) |
| накоп**и**ть | к`опит | нак`апливать (root vowel shifts: о→а) |
| замороз**и**ть | мор`озит | замор`аживать (root vowel shifts: о→а) |
| устр**о**ить | устр`оит | устр`аивать (root vowel shifts: о→а) |
| накол**о**ть | к`олет | нак`алывать (root vowel shifts: о→а) |
| обраб**о**тать | обр`аботка | обраб`атывать (root has а already — no shift) |
| зараб**о**тать | раб`ота | зараб`атывать (root has а already — no shift) |

**Rule of thumb:** If the НСВ form uses the suffix -ывать/-ивать, always prefer another stress test (a noun, an adjective, or a different verb form) instead.

## 8. Exception: заимствованные слова с разными суффиксами

In some loanwords, the unstressed vowel cannot be verified by a related word if the two vowels belong to suffixes of different origin (French vs German, Latin vs Greek, etc.).

| Word 1 | Origin | Word 2 | Origin | Note |
|---|---|---|---|---|
| абонем**е**нт | French -ement | абониров**а**ть | German -ieren | Different suffix vowel |
| аккомпанем**е**нт | French -ement | аккомпаниров**а**ть | German -ieren | Different suffix vowel |
| ангажем**е**нт | French -ement | ангажиров**а**ть | German -ieren | Different suffix vowel |
| апперц**е**пция | Latin -ceptio | апперцип**и**ровать | German -ieren | Different root vowel development |
| дезинф**е**кция | Latin -fectio | дезинфиц**и**ровать | German -ieren | Different root vowel development |
| инъ**е**кция | Latin -iectio | инъ**е**цировать | Latin -icere | Same vowel preserved |
| про**е**кция | Latin -iectio | про**е**цировать | Latin -icere | Same vowel preserved |

The last two rows (инъекция / инъецировать, проекция / проецировать) preserve the root vowel and ARE consistent — included as contrast.

## 9. Unverifiable vowels (непроверяемые)

When no stressed cognate exists, the spelling must be memorized or looked up in a dictionary. Common examples:

- соб`ака, коп`ейка, винегр`ет, ар`омат, корз`ина, кап`итан, гард`ероб
- апельс`ин, экз`амен, палис`адник, багр`овый, интелл`ект
- вестиб`юль, дир`ектор, инжен`ер, календ`арь, преп`одаватель

These are covered in a separate rule (Непроверяемые безударные гласные).
