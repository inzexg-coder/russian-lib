---

| Примечание 1 |
|---|
| Гласные **о — а** в неударяемых корнях глаголов совершенного вида нельзя проверять формами несовершенного вида на **-ывать (-ивать)**. |

| Ошибочная проверка | Правильная проверка |
|---|---|
| опоздать ← опа́здывать (неверно) | опоздать ← по́здний |
| раскроить ← раскра́ивать (неверно) | раскроить ← кро́йка |
| спросить ← спра́шивать (неверно) | спросить ← про́сит |
| закончить ← зака́нчивать (неверно) | закончить ← ко́нчить |
| накопить ← нака́пливать (неверно) | накопить ← ко́пит |
| заморозить ← замора́живать (неверно) | заморозить ← моро́з |
| устроить ← устра́ивать (неверно) | устроить ← стро́й |
| расколоть ← раска́лывать (неверно) | расколоть ← раско́л |

---

| Примечание 2 |
|---|
| В заимствованных словах с суффиксами разного происхождения проверка однокоренным словом невозможна. |

| Нельзя проверять | Происхождение |
|---|---|
| абонемент (-емент фр.) ≠ абонировать (-ировать нем.) | суффиксы разного происхождения |
| аккомпанемент ≠ аккомпанировать | суффиксы разного происхождения |
| ангажемент ≠ ангажировать | суффиксы разного происхождения |
| апперципировать ≠ апперцепция | корни разного происхождения |
| дезинфицировать ≠ дезинфекция | корни разного происхождения |

| Можно проверить |
|---|
| инъекция — инъецировать |
| проекция — проецировать |
