# Дефисное написание частиц

## § 64. Дефисное написание частиц

| Формулировка |
|---|
| Пишутся через дефис частицы **-то**, **-либо**, **-нибудь**, **кое-(кой-)**, **-ка**, **-де**, **-с**, **-тка**, **-тко**. |

### Примеры

| Примеры |
|---|
| кто-то, что-либо, чей-нибудь, кое-какой |
| скажите-ка, на-ка, на-кась, ну-ка, ну-кась |
| нате-ка, нате-кась, он-де, да-с |
| на-тка, на-ткась, ну-тко, гляди-тко |

| Примечание |
|---|
| Если частица, которая пишется через дефис, стоит после другой частицы, то дефис опускается. Если частица попадает в середину сложного слова, часть которого соединяется дефисом, то дефис пишется только перед частицей, а после нее опускается. |
