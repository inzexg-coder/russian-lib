# Названия, связанные с религией

## Бог и имена Бога

| Формулировка |
|---|
| С прописной буквы пишутся слово **Бог**, имена Бога во всех религиях. |

### Примеры

| Пример | Пример | Пример |
|---|---|---|
| Яхве (Ягве) | Иегова | Иисус Христос |
| Аллах | Шива | Брахма |
| Вишну | Перун | Зевс |
| Молóх | Саваоф | Ра |
| Вакх | Гермес | |

---

| Формулировка |
|---|
| Слово **Бог**, как правило, пишется с прописной буквы в составе устойчивых сочетаний. |

### Примеры

| Пример |
|---|
| Бог даст |
| слава Богу |
| помилуй Бог |
| не приведи Бог |
| ради Бога |

---

## Лица Святой Троицы и Богородица

| Формулировка |
|---|
| С прописной буквы пишутся все имена Божии лиц Святой Троицы (**Бог Отец**, **Бог Сын**, **Бог Святой Дух**) и слово **Богородица**, а также все слова, употребляющиеся вместо слов **Бог** и **Богородица**. |

### Примеры

| Пример | Пример |
|---|---|
| Господь | Спаситель |
| Создатель | Всевышний |
| Творец | Царица Небесная |
| Пречистая Дева | Пресвятая Дева |
| Матерь Божия | |

| Примечание |
|---|
| В том числе местоимения, например: *Да святится имя Твое!* |

---

| Формулировка |
|---|
| С прописной буквы пишутся все прилагательные, образованные от слова **Бог**. |

### Пример

| Пример |
|---|
| благодать Божия |

---

## Основатели религий, апостолы, пророки, святые

| Формулировка |
|---|
| С прописной буквы пишутся все собственные имена основателей религий, апостолов, пророков, святых. |

### Примеры

| Пример |
|---|
| Будда |
| Мухáммед (Мохаммéд, Магомет, Магомед) |
| Иоанн Предтеча |
| Иоанн Златоуст |
| Иоанн Креститель |
| Иоанн Богослов |
| Илья Пророк |
| Николай Чудотворец |
| Георгий Победоносец |

---

| Формулировка |
|---|
| Слова **апостол**, **преподобный**, **святой**, **мученик** перед собственными именами пишутся со строчной буквы. |

### Примеры

| Пример |
|---|
| апостол Петр |
| преподобный Сéргий Рáдонежский |
| мученик Порфирий |
| святой Иоанн Кронштадтский |

---

## Нарицательные имена в значении собственных

| Формулировка |
|---|
| С прописной буквы пишутся все нарицательные имена, употребленные в значении собственных. |

### Примеры

| Пример |
|---|
| Небо |
| Сотворение Мира |
| Крест Господен |
| Страшный Суд |
| Церковь |

### Сочетания

| Пример | Примечание |
|---|---|
| Православная Церковь | но: *баптистская церковь*, *англиканская церковь* (нарицательное значение) |
| Святая Церковь | |
| Русская Православная Церковь | |

## Религиозные праздники

| Формулировка |
|---|
| С прописной буквы пишутся первое слово и собственные имена в названиях религиозных православных праздников. |

### Православные праздники

| Пример | Пример |
|---|---|
| Пасха Христова (Пасха) | Рождество Христово (Рождество) |
| Вход Господен в Иерусалим (Вербное воскресенье) | Вознесение Господне (Вознесение) |
| День Святой Троицы, Пятидесятница (Троица) | Крещение Господне (Крещение) |
| Сретение Господне (Сретение) | Благовещение Пресвятой Богородицы (Благовещение) |
| Преображение Господне (Преображение) | Успение Пресвятой Богородицы |
| Воздвижение Креста Господня | Введение во храм Пресвятой Богородицы |
| Покров Пресвятой Богородицы | Усекновение главы Иоанна Предтечи |

### Праздники других религий

| Пример |
|---|
| Байрам |
| Рамазан (Рамадан) |
| Навруз |
| Ханука |
| Шаббат |

| Формулировка |

### Примеры

| Пример |

## Органы церковной власти

| Формулировка |
|---|
| С прописной буквы пишутся все слова в названиях высших органов церковной власти. |

### Примеры

| Пример |
|---|
| Поместный Собор |
| Архиерейский Собор |
| Священный Синод |
| Всемирный Совет Церквей |

---

| Формулировка |
|---|
| В названиях местных органов церковной власти с прописной буквы пишется только первое слово. |

### Примеры

| Пример |
|---|
| Епархиальное собрание |
| Епархиальный совет |
| Приходский совет |

---

## Высшие должностные лица

| Формулировка |
|---|
| С прописной буквы пишутся все слова (кроме служебных слов и местоимений) в наименованиях высших должностных лиц. |

### Примеры

| Пример |
|---|
| Святейший Патриарх Московский и всея Руси |
| Местоблюститель Патриаршего Престола |
| Папа Римский |

---

| Формулировка |
|---|
| Наименования других должностей и званий пишутся со строчной буквы. |

### Примеры

| Пример |
|---|
| митрополит Волоколамский и Юрьевский |
| архимандрит Евгений |
| отец Алексúй |
| игумен Петр |

---

## Церкви, монастыри, иконы

| Формулировка |
|---|
| В названиях церквей, монастырей, учебных заведений, икон слова *церковь*, *храм*, *монастырь*, *академия*, *семинария*, *икона* (*образ*) пишутся со строчной буквы, а их названия и все собственные имена в названиях – с прописной. |

### Примеры

| Пример |
|---|
| храм Зачатия Праведной Анны |
| Казанский собор |
| Киево-Печерская лавра |
| икона Донской Божией Матери |
| образ Знáмения Божией Матери |
| собор Сан-Стефана |

---

## Церковные службы

| Формулировка |
|---|
| Названия церковных служб и их частей пишутся со строчной буквы. |

### Примеры

| Пример |
|---|

| утреня |
| литургия |
| крестный ход |
| всенощная |
